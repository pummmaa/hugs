## Installation
**Arch**
```bash
sudo pacman -S i3-wm
```

[Wiki - ReadMe!](https://i3wm.org/docs/userguide.html)
## Applications (X11)
- **Caffeine-ng** Keep screen on, prevent computer to go to sleep/screen to dim
## Essentials
- **xrandr** Primitive command line interface to RandR extension
	- `sudo pacman -S xorg-xrandr`
- 
## Customization
- **Gruvbox Icons** Gruvbox themed icons
	- [GitHub Repo](https://github.com/SylEleuth/gruvbox-plus-icon-pack)
- **Flashfocus** - Simple focus animation for windows tilling managers X11
	- [GitHub Repo](https://github.com/fennerm/flashfocus)
- **Picom** - Lightweight compositor for X11 and animations
	- [GitHub Repo](https://github.com/yshui/picom)
	- **Installation:** `yay picom-git` *Install the dev version on Arch for all feature to work*
